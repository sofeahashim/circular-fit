# Pitch deck

- `slides-draft.md`: the written outline, slide by slide, with the judging-criteria mapping and open items.
- `deck-source/`: the source of the visual deck (one HTML file per slide plus `deck.json`). It was built as a Claude "Slides" artifact. Open it in claude.ai to present it, or to download a PowerPoint or PDF for submission.
- `screenshots/`: app screenshots used on the slides (synthetic data).

The deck has 10 main slides and 4 appendix slides. Anything marked `[fill in]` still needs the team's details.
